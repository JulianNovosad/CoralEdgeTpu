## Re-Audit Report - 20251208_180702

### Network Ports Configuration Audit

**Summary:** The `network_ports` section in `config.json` currently deviates significantly from the specified structure and content detailed in the `README.md`.

**Details:**

1.  **Structure Mismatch:**
    *   **`config.json` (current):** A flat JSON object where symbolic names are keys and port numbers are values.
        ```json
            "network_ports": {
              "livestream_video": 1001,
              "bounding_box_stream": 1002,
              "reticle_coordinate": 1003,
              "status_telemetry": 1004,
              "phone_orientation_yaw": 2001,
              "phone_orientation_pitch": 2002,
              "phone_orientation_roll": 2003
            }
        ```
    *   **`README.md` (specification):** A JSON object where port numbers are keys, and their values are nested objects containing `purpose`, `comment`, and `module_refs`.
        ```json
        "network_ports": {
          "1001": { "purpose": "video_stream_1536x864_pi_to_phone", "comment": "Streaming encoded 1536x864 live video feed van Pi naar telefoon", "module_refs": ["src/video_overlay_processor.*"] },
          "1002": { "purpose": "bounding_boxes_pi_to_phone", "comment": "Bounding boxes stream", "module_refs": ["logic"] },
          "1003": { "purpose": "reticle_coordinate_pi_to_phone", "comment": "Enkele reticle-coördinaat, verstuurd één keer en opgeslagen op telefoon", "module_refs": ["logic"] },
          "1004": { "purpose": "status_info_pi_to_phone", "comment": "Status: locked/distance/speed", "module_refs": ["logic"] },
          "2001": { "purpose": "yaw_phone_to_pi", "comment": "Orientation: yaw van telefoon naar Pi", "module_refs": ["logic"] },
          "2002": { "purpose": "pitch_phone_to_pi", "comment": "Orientation: pitch van telefoon naar Pi", "module_refs": ["logic"] },
          "2003": { "purpose": "roll_phone_to_pi", "comment": "Orientation: roll van telefoon naar Pi", "module_refs": ["logic"] }
        }
        ```

2.  **Missing Information:** The `config.json` lacks the descriptive `purpose`, `comment`, and `module_refs` fields for each network port, which are vital for comprehensive documentation and automated analysis as per the project's development principles.

3.  **Semantic Discrepancy:** The `README.md` uses the port number as the primary key for network port definitions, facilitating direct lookup and adherence to the network protocol. In contrast, `config.json` employs descriptive string keys, which, while readable, do not align with the structured definition for automated processing.

**Recommendation:** Update the `network_ports` section in `config.json` to strictly adhere to the structure and content specified in the `README.md`. This will involve:
*   Restructuring the `network_ports` object to use port numbers as keys.
*   Populating each port entry with `purpose`, `comment`, and `module_refs` fields as defined.
*   The `module_refs` will be populated by static analysis later as per the master agent prompt.

This change is critical for maintaining consistency, enabling automated configuration validation, and ensuring the application aligns with documented system architecture.
